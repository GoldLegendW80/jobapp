Scope
The proof enumerates registered FastAPI route contexts. Its explicit table must equal
all Apply endpoints plus mail.send_router and browser.later_router endpoints: 45 routes.
Five linked Documents cases supplement this table:editor read/save, version read,
PDF bytes and preview PNG ownership. A new registered scoped route fails table parity.
Bodies validate against the registered FastAPI body field before request assertions.
Signed-out requests return 401, authenticated mutations without CSRF return 403,
foreign objects and missing objects return identical 404 bodies. Collection/settings
exceptions name their authenticated owner semantics in the table.
Query-filtered applications exclude foreign posting IDs. Owner reads return exact
JPEG/PDF bytes and the application's exact draft/send IDs. Cross-parent screenshots
are rejected. Both application and site-profile sign-in callbacks reject B-on-A,
even copied lease metadata, while the owner's repeated completion queues once.
Private successes and 401/403/404/405/422/500 responses carry no-store.

Deletion
Real Postgres at migration head includes 0024 sections, 0025 mail and 0026 answer metadata.
Each owner has committed answers, events, shots, authorisations, site-profile sections,
fields and shots, a mail draft/send, document versions and a frozen PDF.
SQL DELETE exercises database cascades. Fresh sessions assert every affected table,
with exact B counts and IDs preserved. Posting deletion removes application content,
drafts and frozen posting document versions; independent site profiles survive with
their profile authorisation. SPEC-mail's minimal send audit survives content deletion
for its separate 365-day retention. Account deletion removes that audit too.
Screenshot pruning preserves the frozen documents before either deletion.
